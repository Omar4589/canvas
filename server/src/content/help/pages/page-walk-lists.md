The **Walk Lists** page is where you create the parallel operations in your campaign, give each one its doors (by claiming a saved search or all Intake), and manage its passes. It also shows an **Intake** count when new imported addresses are waiting to be claimed, plus each walk list's **crew** — which fills in automatically as you assign books.

Each walk list's **Passes** panel shows every pass with its own numbers — books, knocks, survey doors (lit drops on a lit-drop campaign), and connection rate — counted the same way as the campaign Home's **By pass** breakdown. The panel is always **all-time**; the Home table follows its date range, so they match exactly when the Home range is "All time". An archived pass shows how it ended, and **Bring back** when it can come back (see [Passes](passes)).

## One status per walk list

The **Status** column gives each walk list one plain status:

- **Live · Pass 3** — a pass is live. The **Pass** column names it.
- **Setting up** — no pass has gone live yet; it shows how far along setup is and the next step.
- **Between passes** — a pass has been live and none is live now, like *Between passes · Pass 1 ended Oct 20 · Pass 2 draft*.
- **No passes yet** — the walk list has no pass.
- **Archived** — with when and by whom, and what archiving ended: *Archived Oct 27 by Ada · Pass 3 ended*.

A walk list archived before the October 2026 update may read just *Archived* — nothing recorded the date or who did it then. If its pass was still live, Doorline's one-time check ended it, and the row reads *Archived · Pass 3 ended by the one-time check*; **Unarchive** can bring that pass back. Until the check runs, such a row reads *Archived · Pass 3 still live* in amber, with **End Pass 3**.

## Archived walk lists

Archived walk lists fold into an **Archived walk lists** section at the bottom, closed until you open it. If every walk list is archived, the table says so and points you there. The **Walk Lists** card at the top counts the open ones, with the archived ones under it — *3*, *+2 archived*.

- **Open walk lists** offer **Manage**, **Archive** and **Delete**; **archived** ones **View**, **Unarchive** and **Delete**.
- **Delete** only shows when it can work: every pass of that walk list is still a draft. Doors already recorded there also stop a delete, and the page says so.
- **An archived walk list opens read-only.** You can rename it; everything else reads *Unarchive North to change this.*
- **On an archived campaign** the page shows the campaign's archived banner, and archiving, unarchiving, renaming, deleting, claiming and passes are all off.
