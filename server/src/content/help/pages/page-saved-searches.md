The **Saved Searches** page is where you carve out a named, frozen set of doors — either with the **Filter builder** (party, precinct, district, age, survey answers, plus an **Exclude doors** section for the doors you *don't* want) or with **Upload file**, a CSV or Excel file of Voter IDs (only an Excel file's first tab is read). A saved search built from a file is badged **uploaded**. You then hand that saved search to a walk list to give it its doors. Each saved search can also be downloaded as a spreadsheet — handy for a phone bank or a mail house.

For the full walkthrough, see [Saved searches](saved-searches).
